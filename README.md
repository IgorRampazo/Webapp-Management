# Bimestral Web Application – Registration System

> Projeto acadêmico desenvolvido como trabalho bimestral para aplicação prática de conceitos de desenvolvimento web.

> Academic project developed as a bimonthly assignment to apply web development concepts.

<br>

## Sobre / About

> Este projeto consiste em uma aplicação web com sistema de autenticação e múltiplos módulos de cadastro, desenvolvida como parte de um trabalho bimestral da faculdade. O sistema contempla uma vitrine pública de produtos e áreas restritas para gerenciamento de clientes, produtos, fornecedores, entregadores, categorias e usuários do sistema, atendendo aos requisitos propostos na disciplina.

> This project is a web application featuring an authentication system and multiple registration modules, developed as part of a college bimonthly assignment. The system includes a public product showcase and restricted areas for managing clients, products, suppliers, delivery personnel, categories, and system users, meeting the requirements defined by the course.
